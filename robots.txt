# Content Signals — AI content usage preferences
# Spec: https://contentsignals.org/ · https://datatracker.ietf.org/doc/draft-romm-aipref-contentsignals/
#
#   ai-train=no    content must not be used to train or fine-tune models
#   search=yes     indexing and linking from search results is welcome
#   ai-input=yes   content may be used as input to AI answers, with citation
#
# Position: MysticDo wants to be read by people and cited by answer engines.
# It does not grant model-training rights. Vendors whose crawler token bundles
# training with grounding (Google-Extended, Applebot-Extended) remain crawlable
# deliberately, so the ai-input channel stays open — the preference is declared
# here rather than enforced by a blanket Disallow.
# ─────────────────────────────────────────────────────────────────────────────

Content-Signal: ai-train=no, search=yes, ai-input=yes

# ─────────────────────────────────────────────────────────────────────────────
# THE ACTUAL GUARANTEE
#
# The group below is what keeps every AI search tool unblocked. Any crawler not
# named further down — including one released after this file was written — is
# covered by `User-agent: *` and therefore allowed. Nothing on this site is
# blocked except /_design-check/ (build artefacts, also excluded from the CDN)
# and CCBot (see the last group).
#
# The named groups exist for two reasons only: they document intent, and they
# stay correct if this `*` group is ever tightened. Note that a named group
# REPLACES `*` entirely — it does not inherit from it — so every named group
# below repeats the shared Disallow. Keep it that way.
#
# ⚠️ robots.txt is not the only control layer. A CDN, WAF, bot-management or
# rate-limit rule can block these same crawlers regardless of what is written
# here. On Cloudflare, verify that "Block AI bots" / AI Crawl Control and Bot
# Fight Mode are off (or that the crawlers below are in the allow list) — this
# file cannot override those settings.
# ─────────────────────────────────────────────────────────────────────────────

Allow: /
Disallow: /_design-check/

# unambiguous here and are declined at the crawl level as well as in the
# Content-Signal declaration above.
#
# Note the deliberate asymmetry: a vendor whose crawler also serves answers is
# left allowed even when it also trains, because blocking it would cost
# citations — which is the opposite of what this site is optimising for.
